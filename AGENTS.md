# Server experiment package contract

This branch is a bounded source package, not the full historical research repository.
Read RUN_EXPERIMENT.md, docs/rule_exposure_protocol.md and docs/pilot_registry.json.
Keep this operating contract stable; current results and run status belong in the registry.

The active pilot compares stable-module exposure while always supplying current
dynamic policy parameters. Do not relabel it as chronology superiority or proven
business deployment value. Synthetic structured facts and oracle simulation do
not establish model performance. Completed execution does not confirm a claim.
Do not launch historical experiments or unlock held-out data from this branch.

Default tests use only local synthetic fixtures and mocked processes; no GPUs,
networks, real models or actual corpora. Real work uses the explicit opt-in
execution entry and an allocated device. Once the user requests the documented
campaign with its model/device, run its stages continuously within that budget.
Do not silently add seeds, change labels, increase budgets or retry for better scores.

Preserve unrelated edits and failed artifacts. Do not infer GPU ownership, kill
other users' processes, alter shared environments or replace models silently.
Keep raw outputs local; use fresh campaign directories for design/source changes.

Never commit credentials, machine paths, private corpora, raw logs, generations,
weights, adapters or personal material. Inspect exact staged paths and bytes
before publishing. This repository is a deliberately public, source-only release.
Never import private repository history or change the original private repository's
visibility. Do not force-push or change the default branch. Report precisely
which checks ran and which integrations did not.
