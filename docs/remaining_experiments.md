## 现在一口气跑完

四组同案例、同动态参数、同标签、同顺序、同训练更新预算：
Full-only / Short-only / Whole-mix / Component-mix。
基础模型和四个训练端点评估 Full/Short、原政策/未见组合/未见取值。
自动产出严格评分、受影响/未受影响分析、按案例配对区间和报告。
这是有明确预算的单种子探索，不是正式论文主实验。

## 拿到结果后再决定

先判断模块级曝光是否有值得追的信号，同时检查格式失败和政策变化案例。
有信号时再制定独立种子、更多独立规则版本、自然语言输入及抽取＋规则引擎
对照的正式方案；无优势就按实报告，不反复扩种子直到显著。
如主张效率，还需能力匹配的实际延迟/吞吐测量；输入 token 减少不等于等比例加速。

旧三组五种子的 ABCD 15-run 方案是历史候选，不是当前默认任务。
本轮不重跑旧 MBPP、不扩大退火调度搜索、不加 GRPO，不更改历史论文结论。
